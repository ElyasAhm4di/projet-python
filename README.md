# Projet Python

Un projet Python, structuré dès le départ pour grandir proprement.

## Organisation

- `src/` : le code du projet.
- `tests/` : les tests.
- `requirements.txt` : les dépendances, à créer dès la première bibliothèque installée.

## Démarrer

```bash
python -m venv .venv
source .venv/bin/activate        # Windows : .venv\Scripts\activate
pip install -r requirements.txt
```
